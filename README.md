# Samuel Flores

Personal portfolio for Samuel F. Flores, built with the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) remote theme. GitHub Pages publishes the `main` branch from the repository root, so the site is [https://eagle787sf.github.io](https://eagle787sf.github.io) with no project subpath.

## Homepage

- Name, professional photo (`assets/photo.jpg`), and short bio
- Resume link to `assets/resume.pdf`
- LinkedIn, GitHub, and [floresline.dev](https://floresline.dev/)

## Homework documentation

Add a homework PDF under `docs/` when it is ready, for example `docs/hw1.pdf`. It will be available at `https://eagle787sf.github.io/docs/hw1.pdf` and does not move the portfolio off the site root.
